# 🥗 بوت مدرب التغذية الشخصي الذكي (Telegram Nutrition AI Bot)

بوت تلجرام ذكي متعدد الوسائط (Multimodal AI) يعمل كمدرب تغذية شخصي متصل بنموذج **Google Gemini Vision**. يحلل صور الوجبات، يقدر المكونات والماكروز، ويتابع رصيدك اليومي من السعرات بدقة وتلقائية.

---

## 🎯 الأهداف المبرمجة بالبوت
- **الوزن الحالي:** 73 كجم
- **الهدف:** 67 كجم (خسارة 6 كجم خلال 90 يوماً بتدرج آمن)
- **الميزانية اليومية:** 1,550 سعرة حرارية/يوم
- **التصفير اليومي:** تلقائي مع بداية كل يوم جديد (00:00)

---

## 🚀 دليل التشغيل السريع في 3 خطوات

### الخطوة 1: استخراج مفاتيح التشغيل (مجاناً 100%)

1. **توكن التلجرام (Telegram Bot Token):**
   - افتح تطبيق تلجرام وابحث عن الحساب الرسمي: [`@BotFather`](https://t.me/BotFather).
   - أرسل له الأمر: `/newbot`.
   - اختر اسماً للبوت (مثلاً: `كوتش التغذية`) ثم اسم مستخدم ينتهي بـ `bot` (مثلاً: `MyNutritionCoachBot`).
   - سيعطيك مباشرة رمز التوكن مثل: `123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ`.

2. **مفتاح الذكاء الاصطناعي (Gemini API Key):**
   - ادخل على موقع [Google AI Studio](https://aistudio.google.com/).
   - سجّل بحساب Google واضغط على **Get API Key** ثم **Create API Key**.
   - انسخ المفتاح.

---

### الخطوة 2: إعداد المشروع والمفاتيح

1. انتقل لمجلد المشروع:
   ```bash
   cd /Users/waseem/.gemini/antigravity/scratch/telegram-nutrition-bot
   ```

2. انسخ ملف الإعدادات وأضف مفاتيحك:
   ```bash
   cp .env.example .env
   ```
   افتح ملف `.env` وضع التوكن والمفتاح:
   ```env
   TELEGRAM_BOT_TOKEN=ضع_توكن_التلجرام_هنا
   GEMINI_API_KEY=ضع_مفتاح_جيميني_هنا
   DAILY_CALORIE_TARGET=1550
   ```

3. تثبيت المكتبات المطلوبة:
   ```bash
   pip install -r requirements.txt
   ```

---

### الخطوة 3: تشغيل البوت

شغّل الأمر التالي:
```bash
python bot.py
```

افتح تلجرام، وابدأ المحادثة مع بوتك بالضغط على `/start` وأرسل له صورة أول وجبة! 📸

---

## ☁️ تشغيل البوت 24/7 مجاناً (بدون إبقاء الكمبيوتر مفتوحاً)

إذا أردت أن يعمل البوت على مدار الساعة وأنت خارج المنزل، يمكنك رفعه مجاناً على **Render** أو **Railway**:

1. أنشئ حساباً مجانياً على [Render.com](https://render.com).
2. اختر **New +** ثم **Background Worker**.
3. اربط مستودع GitHub الخاص بك الذي يحتوي على هذه الملفات.
4. اضبط أمر التشغيل: `python bot.py`.
5. في قسم **Environment Variables** أضف:
   - `TELEGRAM_BOT_TOKEN`
   - `GEMINI_API_KEY`
   - `DAILY_CALORIE_TARGET=1550`
6. اضغط **Deploy** وسيعمل البوت للأبد مجاناً!
